# Fiche de Valorisation Stratégique : BatTrack

## 📊 Audit Technique
- **Volume :** ~28 674 lignes de code (LOC) Dart.
- **Architecture :** Modulaire (Feature-First) avec Riverpod 3.
- **Backends :** Hybride Agnostique (Firebase / Supabase / Cloudflare).
- **Stockage Local :** Hive avec synchronisation bidirectionnelle unifiée.

## 💎 Diamants Techniques
1. **Engine de Synchronisation Unifié :** Couche d'abstraction permettant de gérer le cache local et le multi-remote de manière transparente pour les entités métier.
2. **Bridge Dolibarr Natif :** Intégration directe avec l'ERP open-source leader, permettant une adoption rapide par les PME déjà équipées.
3. **Moteur de Devisage Hiérarchique :** Structure (Chantier > Étape > Pièce > Matériaux/Main d'œuvre) avec calcul automatique des marges et coûts.
4. **Générateur PDF Signature-Ready :** Système de génération de documents comptables avec injection de signatures numériques.
